# Metro Ticket Generation System – ServiceNow

## 📌 Project Overview

The Metro Ticket Generation System is a ServiceNow-based application
designed to allow users to select metro stations, generate tickets,
calculate fares and manage ticket-related information.

## 🎯 Objectives

- Allow users to select source and destination stations
- Generate metro tickets
- Calculate ticket fare
- Maintain station information
- Automate ticket generation using ServiceNow
- Provide notifications to users

## 🛠️ Technologies Used

- ServiceNow
- Service Catalog
- Workflow
- Business Rules
- Client Scripts
- Notifications
- JavaScript
